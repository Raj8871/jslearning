# **App Name**: JS Ascent

## Core Features:

- Interactive Tutorials: Interactive tutorials covering JavaScript fundamentals and advanced topics.
- AI Explainer: AI-powered explanations: tool that allows users to input JavaScript variable names or code snippets and receive AI-generated explanations of their functionality.
- Live Code Editor: A built-in code editor to write and execute JavaScript code directly on the webpage.

## Style Guidelines:

- Primary color: Dark blue (#1A202C) for a professional and focused learning environment.
- Secondary color: Light gray (#EDF2F7) for content backgrounds and readability.
- Accent: Teal (#4DC0B5) for interactive elements and highlights.
- Clean and structured layout with clear sections for learning, coding, and AI interaction.
- Subtle animations for UI transitions and interactive feedback.
- Use modern and recognizable icons for navigation and features.
